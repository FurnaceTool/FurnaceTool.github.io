## :material-fire: What is Furnace.json?  
`Furnace.json` is the configuration file used by **Furnace Converter**.  
It functions similarly to `sprite.json` from **java2bedrock.sh**, handling multiple conversion elements for Bedrock Edition.  

Need help setting up and use `furnace.json`? Follow the detailed guide here:
